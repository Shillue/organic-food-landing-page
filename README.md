# 🥦 Projeto: Organic Food Landing Page

Este projeto consiste na criação de uma landing page moderna para uma marca fictícia de alimentos orgânicos, inspirada em um design visual de referência. A proposta foi transformar um layout conceitual em uma interface funcional utilizando HTML e CSS, com foco em responsividade, organização visual e boas práticas de desenvolvimento front-end.

## 🎯 Objetivo

Desenvolver uma landing page profissional para apresentação de produtos orgânicos, aplicando estrutura semântica, design responsivo e estilização moderna com HTML e CSS.

## 🖥️ Sobre o Projeto

A Organic Food é uma landing page voltada para apresentação de alimentos orgânicos frescos e saudáveis.     
O layout segue uma proposta clean e natural, com tons suaves de verde, imagens de alimentos e foco em navegação simples e visual agradável.      
A página apresenta uma seção principal com destaque visual, área de produtos, categorias em evidência e rodapé com links rápidos e redes sociais.

## 📘 Funcionalidades

O projeto inclui os seguintes elementos:

- Header com logo e menu de navegação
- Ícone de perfil
- Seção principal (hero) com chamada de destaque
- Botão de ação “Our Products”
- Área com cards de produtos
- Seção de categorias em destaque:
  - Vegetais Orgânicos
  - Natural & Saudável
- Links rápidos no rodapé
- Ícones de redes sociais
- Layout totalmente responsivo
- Navegação por âncoras internas

## 🏷️ Tecnologias Utilizadas

### HTML

- Estrutura semântica:
  - `<header>`
  - `<main>`
  - `<section>`
  - `<nav>`
  - `<footer>`
- Uso de listas para produtos e menu
- Links internos com âncoras
- Imagens com atributo `alt`

### CSS

- Variáveis CSS (`:root`)
- Flexbox para layout
- Background com imagem + gradiente
- Hover effects e transições
- Box-shadow
- Responsividade com media queries
- Separação de estilos:
  - `style.css`
  - `responsive.css`

## 🧠 Aprendizados

Durante o desenvolvimento, foram praticados:

- Estruturação de layout a partir de um design visual
- Organização de arquivos HTML e CSS
- Uso de Flexbox para alinhamento
- Criação de cards responsivos
- Trabalhar com imagens e background combinado com gradiente
- Ajustes responsivos para tablet e mobile
- Boas práticas de semântica HTML
- Uso de variáveis CSS para padronização visual
